# FairLens audit data

Public supplement for https://fmenegui.com/blog/system-one-fairlens/.

The CSV contains 228,760 recorded evaluations and 104 columns, including image identifiers and hashes, prompts, reconstructed API requests, recorded responses, choices and scores. Analysis code is not distributed. The article retains the methodology, results and references. No API credentials or complete image bank are included.
